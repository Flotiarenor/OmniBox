# 分层豁免：media-player
#
# 为什么有这份文件：tools/check_plugin_layering.py 的 R1（禁 Mixin 切分）、R2（文件行数）、
# R3（只有入口可以加载兄弟模块）对尚未组件化的插件必然先失败。豁免按**插件**粒度分文件，
# 好让多个智能体并行迁移时各删各的，不会改到同一个共享清单。
#
# 它怎么消失：迁移完成后删掉整个文件（迁移配方的最后一步）。留着不删会被门禁判为
# 「豁免文件已过期」并报错；文件存在期间，每次跑门禁都会打印一条 warning 提醒。
# 本文件正文只是当前违规的快照，供迁移时对照使用；门禁只检查文件是否存在。
#
# 迁移配方见 docs/plugin-backend-layout.md。
#
