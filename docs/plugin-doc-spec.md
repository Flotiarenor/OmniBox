# 插件约定文件规格（`plugins/<plugin>/AGENTS.md`）

这些文件放在**插件目录内**，不放在 `docs/`：在插件目录里工作时，支持 `AGENTS.md` 的工具会把
项目根、`plugins/`、`plugins/<plugin>/` 三份约定依次加载，约定因此在需要它的那一刻被读到，
不需要任何人记得去翻文档；内容与代码同目录，改动也能在同一处被看见。

这些文件的**唯一职责**是让人和 agent 快速定位代码：某个功能在哪个文件、哪个符号、哪个选择器。
因此只写"在哪里"，不写"为什么"。

为什么：理由与历史一旦写进文档，就没有人负责更新；而过期的理由会被 agent 当成现状读，
造成无法追踪的遗留问题。设计理由的正确位置是**代码旁的注释/docstring**与**提交信息**。

## 头行（文档第一行，必需）

```
> <plugin> ｜ manifest: plugins/<plugin>/manifest.json
```

## 五节：每节写什么

每份文件由以下五节构成，按顺序、标题用二级。

### 1. `## 定位与形态`

- **一句话职责**：说清"做什么、怎么做"（例：浏览本地图片目录，把文件夹聚合为相册树，并以混合瀑布流与灯箱查看图片）。
- **形态**：独立页插件（给出 `frontend.route` 值）；若同时是宿主，写明承载 companion 的容器选择器与哪些插件依赖它；若是内嵌 companion，写明宿主插件名与入口。
- **`manifest.json` 关键字段逐项列值**：`name`、`backend.entry`、`backend.class`、`frontend.entry`、`frontend.route`、`keepAlive`、`permissions`、`dependencies`、`icon`。

不写：功能清单、卖点、使用说明。

### 2. `## 文件地图`

一张表，**每个源码文件一行**（每个后端分片、`index.html`、插件 CSS、每个 `js/*.js`）：

| 文件 | 职责 | 关键符号 |
| --- | --- | --- |
| `plugins/<plugin>/backend/main.py` | 类骨架、设置 schema、API 注册、诊断 | `XxxPlugin`、`register_api`、`settings_schema` |

- 「关键符号」列用反引号列出该文件里的类名 / 函数名 / CSS 变量 / 选择器，用 `、` 分隔；一个文件列十几个符号是正常的，这是本表的主要价值。
- 表后补一行：**落盘产物**（数据根与 `cache_dir` 下的文件名）及其读写符号。

不写：逐行解释实现、调用链叙述。

### 3. `## 后端 API 契约`

两张表：

- **对外方法**：`register_api` 暴露的方法 → 入参 / 返回 / 用途；
- **壳按名调用的成员**：方法名 → 入参 / 返回 / 用途。

入参与返回按实际签名写；返回形状里的字段名逐个照抄，不省略、不改写。

不写：函数体代码、实现步骤。

### 4. `## 前端结构`

- **DOM 结构树**：缩进列表，每个节点标注 CSS 选择器 / id / 类名；
- **脚本装载顺序**：`index.html` 中 `<script>` 的先后；
- **动态渲染的类名清单**：由脚本拼接、静态搜索看不到的那些类名。

不写：行号、行数、DOM 片段代码块。

### 5. `## 与壳的契约`

只列本插件**用到的**：壳类、壳 CSS 变量、插件自有 CSS 变量前缀、共享前端组件（如 `createLightbox`、`createPagination`）、共享后端基建（如 `FreshnessMixin` 依赖的壳引擎）。末尾指向 `docs/plugin-ui-guide.md`。

不写：重复解释壳的行为、把壳的接口再抄一遍。

## 锚点规则（唯一允许的定位方式）

允许：文件路径（相对仓库根）、CSS 选择器、DOM id、类名、CSS 变量名、函数名 / 类名 / 方法名、
`manifest.json` 字段名。

禁止：行号（`文件:行号`、`css:216`、`第 N 行`）、行数、"上面那个函数"这类位置式措辞、
会随代码漂移的长代码块、空代码片段、空括号、缺宾语的句子。

## 锚点必须真实存在

每个锚点（路径、选择器、id、函数名、API 名、字段名）都必须能在代码里搜到，逐字符照抄。
**写错名字比写行号更糟**：行号一眼能看出过期，错名字看起来是对的。

写完用 `rg` 抽查即可，例如：

```bash
rg -n "class ImageCleaner" plugins/image-cleaner/backend/main.py
rg -n "\.cleaner-group" plugins/image-cleaner/frontend/
```

查不到就改对；确实拿不准就删掉该锚点，不要猜。

## 体积

每份 ≤ 400 行。超出说明在写实现细节，而不是在写定位地图。
