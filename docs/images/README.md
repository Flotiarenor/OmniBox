# docs/images —— 文档配图

本目录存放**文档用**的界面截图。注意区分：

- `res/` 是随发行包分发的运行时资源（图标 sprite），会进 PyInstaller 的 `datas`；
- `docs/images/` 只被 Markdown 引用，**不会**被打进发行包。

## 拍摄约定

- **尺寸**：应用默认窗口为 1400×900（[main.py:253](../../main.py#L253) 的 `create_window`）。
  现有截图基本为 1692×946（同机缩放下的一致尺寸），`11-pixiv-sync.webp` 为 1694×978；
  换图时保持宽高比接近、不要裁掉左侧导航栏即可。
- **格式**：WebP，由 PNG 截图转换而来（`libwebp`，`-quality 90 -preset text`）。界面截图文字密集，
  **不要**转 JPEG——文字边缘会发虚。
- **体积**：单张 200 KB 以内，`readme/` 合计约 0.9 MB。新增或替换截图时先存成 PNG，再转换：

  ```bash
  ffmpeg -i 原图.png -c:v libwebp -quality 90 -compression_level 6 -preset text \
      docs/images/readme/NN-name.webp
  ```

  原图 PNG 不进仓库（同尺寸下 PNG 约为 WebP 的 3~4 倍）。
- **窗口模式优先**：桌面窗口截图没有地址栏；用 `--web-only` + 浏览器截图时，请用 F11 全屏
  或固定视口，避免地址栏、书签栏、浏览器标签入镜。
- **一致性**：同一批图用同一主题（深浅色除外）、同一导航栏宽度拍摄，避免图与图之间风格跳变。

## 素材与隐私红线

截图里**不允许**出现本机真实数据。`data/`、`.config/` 都被 git 忽略，正因为它们是用户数据。

拍摄前请：

- 用一份**合成示例数据**目录充当 `data_root`（自己生成的占位图片、几段音频、一个 epub/txt），
  不要用真实相册、真实收藏、真实漫画；
- 避开或替换掉本机绝对路径：设置 →「数据与缓存」「诊断」会显示 `data_root` 与日志目录，
  含用户名；插件里的「目录 / 本机目录」字段同理；
- 避开可以指向个人的标识：netease-music 的登录态、pixiv-sync 的 Cookie 与 UID、
  group-mesh 的节点名与共享标识；
- 不要拍到 `.config/auth_token.txt` 的内容。
