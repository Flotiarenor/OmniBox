# docs/images —— 文档配图

本目录存放**文档用**的界面截图。注意区分：

- `res/` 是随发行包分发的运行时资源（图标 sprite），会进 PyInstaller 的 `datas`；
- `docs/images/` 只被 Markdown 引用，**不会**被打进发行包。

## 目录

- `readme/` —— 根目录 [readme.md](../../readme.md) 的配图。编号是**稳定槽位**：不随 README 里的出现顺序调整，
  新增截图顺延取下一个号。

## 怎么重新拍

截图由脚本生成，不手工拍：

```bash
# 1) 配置台：起一个隔离实例的桌面窗口，在里面把基线调成要拍的样子（只需配一次）
python tools/shoot_readme_setup.py

# 2) 拍摄：13 张一起拍（--only 01-hero 单拍，--check 只断言不出图）
python tools/shoot_readme.py
```

- 场景表是 [tools/readme_scenes.json](../../tools/readme_scenes.json)：每个槽位的路由、主题、点击顺序、
  拍摄位置，以及**必须出现的文案**。断言就是"图文一致性"门禁 —— 界面一改，`--check` 立刻指出哪张过期，
  而不是等人肉眼发现。
- 少数步骤由 [tools/scenes/](../../tools/scenes/) 下的小脚本完成（`.js`）：`11` 要把 pixiv 状态栏
  补成示例数据并停掉它的定时刷新，`01` 要把第一个画师「提升到全部相册」（幂等，重复运行不会收回去）。
- 需要 selenium 与 Chrome（`requirements-e2e.txt`，刻意不进 CI）。
- 基线在 `.build/shoot/home`（gitignore）：库路径、主题、背景、宽度都在那里，由配置台维护；
  `--reset` 会重置成空白基线，旧配置自动存档到 `.build/shoot/baseline-<时间戳>`。
- 场景对基线的**覆盖会打印出来**（如 `覆盖基线：background.fit: 'cover' → 'free'`，
  即 `12` 为了让「位置」滑块出现而改显示方式），避免"我配了却没生效"与"场景覆盖了"分不清。
  每场开拍前壳偏好都会先还原成基线，所以场景之间互不影响、顺序无关。

## 拍摄约定

脚本已经保证的部分：

- **尺寸**：视口固定 1692×946（用 CDP 固定，与浏览器窗口边框无关）。
- **只抓视口**：图里没有地址栏，**也没有桌面窗口的标题栏**——这是刻意的取舍。
- **有头浏览器**：无头会跳过 GPU 合成与光栅化，与 WebView2 差距过大。
- **格式**：WebP，`ffmpeg -c:v libwebp -quality 90 -compression_level 6 -preset text`；
  没有 ffmpeg 时退回 Pillow（拿不到 `preset text`）。
- **体积**：单张 200 KB 以内，`readme/` 合计约 1 MB。转换前不落 PNG 进仓库。

需要人在配置台里定的部分：

- 主题、导航栏宽度、各插件内边栏宽度、背景图与玻璃参数；
- 各插件的库根目录（图片相册 / 漫画 / 媒体 / 文档 / Pixiv 下载目录）；
- 团体组网的共享项（`07` 要拍这一屏）。

**一致性**：同一批图用同一套外观设置拍，图与图之间不要风格跳变 —— 基线的意义就在这里，
配一次，13 张都跟着走。

## 素材红线

截图里**不允许**出现本机真实数据。`data/`、`.config/` 都被 git 忽略，正因为它们是用户数据。

拍摄基线是**隔离且空白起步**的（`tools/shoot_readme_setup.py` 生成）：不从仓库 `.config` 复制任何
东西，所以真实库路径、账号令牌、歌单记录都不会进基线，也就不会进截图。拍摄时脚本再把基线复制到
临时目录，跑完即弃。

另外两条：

- 截图里不要出现本机绝对路径（设置 →「数据与缓存」「诊断」会显示 `data_root` 与日志目录，含用户名）；
- 插件页里的「目录 / 本机目录」字段同理；`11` 的 pixiv 统计是拍图时补上去的示例数据，
  不是任何真实账号的规模。

## 配图更新

界面改动后截图会过期。按上面的「怎么重新拍」跑一遍即可，同槽位同名覆盖，README 不需要改；
`python tools/shoot_readme.py --check` 可以只检查"图与界面是否还对得上"，不出图。
