## 仍然成立的顺序结论

1. **P1 壳侧主体上下文最先**——它是"授权"有意义的前提。壳侧第 1/2/5 项已完成，
   第 3 项（数据路由）与插件侧限权仍未做（本轮按决定暂缓，见 §4.8、§4.9）。
2. **私钥保护第二**——复核当时明文落盘是最高危偏离；本轮已完成
   （DPAPI / keyring / 口令 AES-GCM，见实现路径文档 §4.1）。
3. **Noise 换 vetted 实现第三**——已完成（`noiseprotocol` + cacophony 官方向量，
   见实现路径文档 §4.2）。
4. **名单自动分发第四**——已完成（`op=roster` + 名单历史），不再依赖"可信中转方"。
5. **内容寻址最后**——与上述四项无依赖，当前 offset/length 分块在功能上够用。
