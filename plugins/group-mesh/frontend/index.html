    创建团体

    创建后你成为群主。把生成的邀请串通过可信渠道交给成员，他们才能加入。

    邀请串

    通过可信渠道（面对面 / 二维码 / 局域网）交给成员，让他们在本机"加入 / 更新团体"。

    加入 / 更新团体

    粘贴群主给你的最新 gm1: 邀请串。
    · 本机还没有团体时会加入该团体；
    · 本机已有旧名单时会更新到这一版（群主每次加人后都要把新邀请串发给你， 否则你会停在旧名单上，看不到新成员、也连不上他们）。

    添加成员

    让对方在它的"本机身份"里点"显示公钥"，把主体与设备公钥贴到这里。
